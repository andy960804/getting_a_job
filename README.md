# Career-Harness v1.0

> **한국형 자소서 작성을 위한 AI 기반 취업 시스템**
> 3C4P 프레임워크로 경험을 구조화하고, AI 탐지를 회피하는 고품질 자소서를 만듭니다.

---

## 이 프로젝트가 뭔가요?

Claude Code(AI)를 취업 코치로 활용하는 시스템입니다. 채용 공고를 붙여넣으면 AI가 공고를 분석하고, 당신의 경험을 체계적으로 정리해 자소서 초안부터 최종본까지 만들어줍니다.

### 핵심 철학 (면접왕 이형 자소서 바이블 기반)
- 자소서는 **비즈니스 문서**입니다. 글쓰기 실력보다 **경험의 해석 역량**이 합격을 결정합니다.
- 자소서는 **면접의 요약본**입니다. 면접관이 꼬리 질문하고 싶은 소재를 전략적으로 심습니다.
- **역기획 원칙**: 받고 싶은 면접 질문을 먼저 정하고, 거기에 맞게 자소서를 설계합니다.

---

## 시작하기 전에 필요한 것

1. **Claude Code** 설치 — [claude.ai/code](https://claude.ai/code)
2. 이 프로젝트 폴더를 Claude Code의 작업 디렉터리로 열기
3. 본인의 이력/경험 정보

## 사용 방법

### 루트 A — 공고가 먼저 있을 때 (가장 일반적인 경우)

```
1단계: Claude Code를 열고 채용 공고 URL 또는 전문을 붙여넣기
       → AI가 자동으로 analyst → archivist → ghostwriter 순서로 진행합니다

2단계: analyst가 공고를 분석합니다
       → 필요 역량 Top 5, 컬처핏 키워드 Top 3, 지뢰 목록 생성
       → db/jd_analysis/회사명_직무.md 로 저장

3단계: archivist가 내 경험과 공고를 매칭합니다
       → 기존 경험 DB를 탐색하거나, 새 경험을 3C4P로 구조화
       → db/experiences/YYYYMMDD_경험명.md 로 저장

4단계: ghostwriter가 자소서를 씁니다
       → v1 초안 작성
       → [비즈니스 레터 7항 체크] → v2 리라이팅
       → [Anti-AI 15항 체크] → v3 최종본
       → db/drafts/회사명_직무_v3.md 로 저장
```

**입력 예시:**
```
아래 공고를 분석하고 자소서 작성까지 진행해줘.

[채용 공고 전문 붙여넣기]
```

---

### 루트 B — 경험 정리가 먼저일 때

취업 준비 초반에 본인의 경험을 미리 DB로 쌓아두는 방식입니다.

```
1단계: 경험 서술을 Claude Code에 입력
       → archivist가 3C4P Linter(7단계 검사)를 실행
       → 빠진 항목은 AI가 질문으로 채워줍니다

2단계: 경험 카드가 db/experiences/ 에 저장됩니다

3단계: 나중에 공고가 생기면 루트 A의 archivist 단계로 합류
```

**입력 예시:**
```
내 경험을 정리해줘.

대학교 3학년 때 마케팅 동아리에서 SNS 계정 운영을 맡아서
인스타그램 팔로워를 3개월 동안 500명에서 2,000명으로 늘렸어.
콘텐츠 기획부터 디자인, 업로드까지 혼자 다 했고,
매주 성과 데이터를 분석해서 포스팅 시간대와 해시태그를 최적화했어.
```

## 3C4P 프레임워크란?

마케팅의 3C 분석 + 4P 믹스를 자소서 경험 서술에 적용한 구조입니다.

| 구분 | 의미 | 자소서에서의 역할 |
|------|------|-----------------|
| C1 Customer | 혜택을 받는 대상 | 내가 왜 이 일을 했는가 (배경) |
| C2 Company | 내가 속한 조직의 목표·문제 | 조직 내 나의 역할 |
| C3 Competitor | 조사한 외부 사례·경쟁 요소 | 판단의 근거 |
| P1 Product | 결과물 (What) | 무엇을 만들었는가 |
| P2 Place | 문제 발견 지점 (How) | 어디서·어떻게 실행했는가 |
| P3 Price | 비용·시간 절감 효과 | 수치화된 임팩트 |
| P4 Promotion | 설명·공유·설득 방식 | 어떻게 알리고 설득했는가 |

**서술 순서**: P1(결과 먼저) → C1+C2+C3(맥락) → P2+P3+P4(실행 방법) → 인사이트

> 자세한 포맷: `rules/skills/archivist/card_format.md` 참조

## 필살기 경험이란?

자소서 문항의 61%가 필살기형입니다. 필살기는 아래 3요소를 모두 갖춰야 합니다:

| 요소 | 설명 | 위치 |
|------|------|------|
| 유사경험 | "나는 이 직무와 접점이 있다" 신호 | 도입부 |
| 성공경험 | 수치·비교우위로 재현 가능성 증명 | 본문 |
| 인사이트 | 나만의 사고방식·학습 능력 | 마무리 |

**수치화 원칙**: 모든 경험은 KPI로 설명 가능합니다.
- 비포-애프터: "기존 3일 → 1일로 단축"
- 창출: "기존에 없던 X를 개발"
- 건수·기간·인원: "50건 처리", "6개월 운영"
- 외부 검증: 수상, 채택, 승인

## 자소서 버전 게이트

v3 최종본이 나오기까지 3개의 품질 게이트를 통과해야 합니다.

```
v1 초안
  ↓
[GATE 1] 비즈니스 레터 체크 7항  ← 내용·구조 검사
  ↓
v2 리라이팅
  ↓
[GATE 2] Anti-AI 체크 15항       ← 인간 작성 확률 80% 이상 목표
  ↓
v3 최종본
  ↓
[GATE 3] 제출 전 최종 점검 7항  ← 글자수·사실 확인
  ↓
제출
```

> 체크리스트 전문: `rules/skills/ghostwriter/checklists.md` 참조

## AI 자가학습 루프

실수가 발생하면 AI가 자동으로 학습해 같은 실수를 반복하지 않습니다.

```
실수 감지 (사용자 정정 / 게이트 반복 실패 / 파일 불일치)
  ↓
db/error_log.md 에 구조화 기록
  ↓
rules/lessons_learned.md 에 규칙 추가
  ↓
해당 에이전트의 Learned Constraints 동기화
  ↓
동일 실수 2회 이상 → Hard Constraints로 격상 (영구 차단)
```

## 첫 시작 가이드 (Step-by-Step)

### Step 1: 목표 설정
`db/profiles/target_profile.yaml` 을 열어 본인의 목표 직무·연봉·선호 지역을 입력하세요.

### Step 2: 이력서 입력
`db/cv.md` 에 본인의 마스터 이력서를 작성하세요. 이 파일이 모든 자소서의 단일 소스입니다.

### Step 3: 경험 정리 (선택, 권장)
본인의 주요 경험 3~5개를 루트 B 방식으로 미리 정리해두면 자소서 작성 속도가 빨라집니다.

### Step 4: 공고 입력
원하는 회사의 채용 공고를 복사해서 Claude Code에 붙여넣고 시작합니다.

## 주의사항

- `rules/` 폴더 안의 파일은 직접 수정하지 마세요. AI가 학습하며 자동으로 업데이트합니다.
- `db/` 폴더는 사용하면서 자연스럽게 채워집니다. 처음엔 비어 있어도 됩니다.
- 경험을 지어내거나 과장하면 AI가 `[미확인]` 태그를 달고 확인을 요청합니다.
