# Skill: 3C4P Linter

경험 서술 입력 → 저장 전 7개 항목 순서대로 검사.
**하나라도 FAIL → 저장 거부 + 해당 추가 질문 즉시 출력**

## KPI 전환 질문 (수치가 없다고 느낄 때 순서대로 사용)
| # | 질문 | 예시 |
|---|------|------|
| 1 | 투입한 시간·기간은? | "3주", "주 5시간" |
| 2 | 몇 명과? 내 기여 비율은? | "5명 중 기획 1인", "작업의 40%" |
| 3 | 처리한 건수·분량·규모는? | "50건 분석", "A4 30페이지" |
| 4 | 이전과 무엇이 달라졌나? | "3일→1일로 단축" |
| 5 | 몇 명에게 영향을 미쳤는가? | "팀원 12명", "사용자 200명" |
| 6 | 반복 횟수·빈도는? | "월 2회 발표", "15회 실험" |
| 7 | 외부 검증(수상·채택·피드백)은? | "최우수상", "전사 도입" |
> 7개 소진 후에도 없으면 경험 자체를 더 구체적으로 재서술 요청.

## Linter 검사표
| # | 레이어 | 검사 기준 | FAIL 시 질문 |
|---|--------|-----------|-------------|
| 1 | C1 Customer | 수혜 대상·니즈 특정됐는가? | "혜택 받은 대상이 누구인가요? 그들의 필요는?" |
| 2 | C2 Company | 조직 도전과제·내 역할 명시됐는가? | "팀의 목표·상황은? 본인 역할은?" |
| 3 | C3 Competitor | 벤치마킹 대상 명시됐는가? (없으면 '없음') | "조사한 사례가 있나요? 없으면 '없음'으로." |
| 4 | P1 Product | 결과물과 의미 서술됐는가? | "최종 결과물은? 어떤 의미가 있었나요?" |
| 5 | P2 Place | 해결 지점·채널 명시됐는가? | "어디서, 어느 채널로 해결했나요?" |
| 6 | P3 Price | KPI 수치로 가치 증명됐는가? | "수치화해주세요. (위 KPI 전환 질문 참조)" |
| 7 | P4 Promotion | 공유·적용 방식·반응 서술됐는가? | "결과물을 어떻게 알리거나 적용했나요?" |

## 출력 포맷
**FAIL 시**
```
🔴 3C4P Linter — 보완 필요
FAIL: [레이어명]
→ [추가 질문]
보완 후 다시 알려주시면 저장합니다.
```
**PASS 시**
```
✅ 3C4P Linter — 전체 통과
→ db/experiences/에 저장합니다.
```
