# Skill: 필살기 판정 프레임워크

## 필살기 3요소
| 요소 | 정의 | 확인 질문 |
|------|------|-----------|
| 유사경험 | 지원 직무와 관련·비슷한 경험 (옆에서 본 경험도 포함) | "이 경험이 지원 직무와 어떤 접점이 있는가?" |
| 성공경험 | 수치화된 비교우위 — 유사 조건의 타인 대비 우월한 결과 | "비포애프터 / 무에서유 / 수치상승 중 어디에 해당?" |
| 인사이트 | 직무·산업·직장 연관 나만의 사고방식 + 학습능력 증거 | "전문가 조언·원칙과 어떻게 연결되는가?" |

## 성공경험 3유형
| 유형 | 예시 |
|------|------|
| 비포-애프터 | 사고 판정률 90% 달성, 처리 시간 3일→1일 |
| 무에서 유 창출 | 신제품 개발로 공모전 1등, 신규 프로세스 구축 |
| 수치 상승 | 데이터 전송시간 90% 감소, 팀 생산성 30% 향상 |

## 5대 핵심역량 피라미드 (태그 기준)
```
        [목표달성능력] ← 최상위
   [문제해결] [실행·추진력] [리더십]
       [분석력] [의사소통력]
```
태그는 가장 강하게 드러나는 역량 1~2개 선택.

## 판정 기준
- **A급** [필살기 A급]: 3요소(유사+성공+인사이트) 모두 충족
- **B급** [필살기 B급]: 2요소만 충족
- 목표: A급 3~5개 확보
