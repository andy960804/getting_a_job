# Skill: 한국형 문체 & AI 탐지 회피

## 문단 구조 비율
```
[소제목]  "~~을 통해 ~~ 달성" (How + Result)
[3C 배경] 30~40% — 4P보다 많으면 안 됨. 4P와 무관한 배경은 삭제
[4P 실행] 50~60% — How 먼저. 소제목에 Product 언급했으면 Place·Price·Promotion 중심
[Insight] 선택 — 글자수 부족 시 생략
```

## 글자수 조절
| 상황 | 방법 |
|------|------|
| 늘려야 할 때 | 4P 서술 확장 |
| 줄여야 할 때 | 3C 압축 |
| 300자 이내 차이 | 3C 고정, 4P 조정 |
| 500자 이상 차이 | 재작성 |

## 문장 리듬 (Burstiness)
- 짧은 문장(7–15자) ↔ 긴 문장(30–50자) 교차
- 동일 어미 3회 연속 금지 → 로테이션: `~했습니다` / `~하게 됐습니다` / `~임을 확인했습니다` / `~하는 결과로 이어졌습니다`
- 소제목: HOW+RESULT 형식. 명언·비유·슬로건 금지
- 문단 시작 금지: "저는" "귀사에 지원하게 된" "항상 ~을 추구해온"
- 문단 시작 권장: 장면("마감 6시간 전,") / 수치("1,200건이었습니다") / 역설("틀렸다는 걸 알면서도")
- 접속사: 문단당 1회 이하 / 부사("매우","정말"): 전문 3회 이하
- 수동태 → 능동태: "~이 이루어졌습니다" → "제가 ~를 했습니다"

## AI 상투어 블랙리스트
| 금지 표현 | 대체 |
|-----------|------|
| "다양한 경험을 통해" | 경험명 직접 기재 |
| "열정을 가지고" | 구체적 행동 ("새벽 2시까지 ~했습니다") |
| "성장할 수 있었습니다" | 무엇이 달라졌는지 구체 서술 |
| "귀사의 발전에 기여하고 싶습니다" | 직무와 연결된 구체적 기여 방식 |
| "어려움을 극복하고" | 장벽→선택→결과 순 서술 |
| "팀워크를 발휘하여" | 본인 역할 동사로 명시 |
| "주도적으로" | 실제 주도한 행동 기재 |
| "끊임없이 노력하며" | 삭제 후 행동 동사 대체 |
| "시너지" / "레버리지" | 한국어 동사로 풀어쓰기 |
| "~함으로써" 남발 | 2문장으로 분리 |
