# Skill: 한국형 문체 & AI 탐지 회피

## ⚠️ 톤앤매너 — 최우선 원칙

자소서는 비즈니스 문서다. 모든 문장은 반드시 **~습니다/~했습니다/~겠습니다** 체로 종결한다.
링커리어 합격 자소서 280건 전수 확인 결과 예외 없이 100% 습니다체 사용.

| 금지 어미 | 대체 |
|-----------|------|
| ~했다 | ~했습니다 |
| ~이다 / ~다 | ~입니다 |
| ~봤다 | ~확인했습니다 |
| ~됐다 | ~됐습니다 / ~이어졌습니다 |
| ~같다 / ~같았다 | ~라고 판단했습니다 |

> 작성 후 ~했다/~이다/~봤다 전수 검색 → 습니다체로 일괄 교체 필수

---

## 소제목 형식 (실제 합격 자소서 기준)

**원칙: [HOW + RESULT]** — "어떻게 해서(HOW) 무엇을 달성했는지(RESULT)"를 한 줄에 압축.
**[대괄호] 형식이 표준.** 쌍따옴표도 허용.

```
HOW+RESULT:  [생산라인 단일화(HOW)로 30%의 초기 투자 비용 절감(RESULT)]
역량 중심:   [생산기술의 핵심, 최적 공정 설계와 협업 역량]
인사이트:   [어려움을 기회로 바꾸는 힘]
쌍따옴표:   "불량 분석 역량" / "협업의 가치 : 시너지"
```

소제목 금지:
- 명언·비유·슬로건 단독 (근거 없는 멋진 말)
- 직무명 반복 ("생산기술 역량")

## 단락 연결 패턴 (실제 합격 자소서 기준)

### 배경(3C) → 실행(4P) 전환
```
[배경 1~2줄 — 문제/상황]
"~한 상황이었습니다."

[실행 전환 — 행동 동사로 직진]
"이에 [행동 동사]했습니다."          ← "이에" 사용 가능
"우선 [행동 동사]했습니다."          ← 순서 부여
또는 접속사 없이 바로 행동 동사로 시작

[결과]
"그 결과, [수치]로 이어졌습니다."
"그 결과 [수치]를 달성했습니다."
```

전환 금지 패턴:
- "이에 저는 ~했습니다" → "저는" 삭제, "이에 ~했습니다"로
- "이 문제를 해결하기 위해" → 삭제 후 행동 동사로 시작
- "다음과 같이 진행했습니다" → 삭제 후 바로 행동으로

### P → P 연결
```
P3 Price → P4 Promotion:
"[수치]를 달성했으며, 연말 [발표/공유]에서 [인정/수상]을 받았습니다."
```

### 인사이트 전환
```
허용: "이러한 경험을 통해 ~라는 것을 확인했습니다." (수치/행동과 반드시 결합)
금지: "이러한 경험을 통해 많은 것을 배웠습니다." (공허한 마무리)
```

## 첫 문장 권장 패턴 (실제 합격 사례)

| 유형 | 예시 |
|------|------|
| 직무 본질 정의 | "생산기술 엔지니어에게 가장 중요한 역량은 ~입니다." |
| 업계/회사 이슈 | "최근 1년 사이 하이브리드 차량 생산량은 전년 대비 46% 이상 증가했습니다." |
| 결론 선제시 | "공정기술 직무는 LG에너지솔루션의 고품질 2차 전지 생산에 기여하는 직무입니다." |
| 장면 오프닝 | "학부 실습 마지막 날, 도면대로 가공한 부품이 조립 치구에 들어가지 않았습니다." |

금지 오프닝: "저는", "귀사에 지원하게 된", "항상 ~을 추구해온"

## 마무리 문장 권장 패턴

```
"~하는 엔지니어가 되겠습니다."          ← 가장 많이 쓰임
"~에 기여하겠습니다."
"~에 이바지하겠습니다."                 ← 격식체
"~해 나가겠습니다."                     ← 지속성 강조
"~하고 싶습니다."                       ← 소망형 (다소 약함, 마지막 문장엔 자제)
```

---

## 문단 구조 비율

```
[소제목]  [결과/역량/인사이트] 형식
[3C 배경] 30% 이하 — 1~2문장으로 압축. 4P보다 많으면 안 됨
[4P 실행] 60% 이상 — 행동 동사 중심. "이에/우선/그 결과" 연결
[Insight] 선택 — 글자수 여유 있을 때. "이러한 경험을 통해" + 구체적 내용
```

## 글자수 조절

| 상황 | 방법 |
|------|------|
| 늘려야 할 때 | 4P 행동 서술 확장 (How 세분화) |
| 줄여야 할 때 | 3C 배경 압축 (핵심 1문장) |
| 300자 이내 차이 | 3C 고정, 4P 조정 |
| 500자 이상 차이 | 재작성 |

---

## 문장 리듬 (Burstiness)

- 짧은 문장(7–15자) ↔ 긴 문장(30–50자) 교차
- 동일 어미 3회 연속 금지 → 로테이션: `~했습니다` / `~하게 됐습니다` / `~임을 확인했습니다` / `~하는 결과로 이어졌습니다`
- 접속사: 문단당 1회 이하 / 부사("매우","정말"): 전문 3회 이하
- 수동태 → 능동태: "~이 이루어졌습니다" → "~를 완료했습니다"

## AI 상투어 블랙리스트

| 금지 표현 | 대체 |
|-----------|------|
| "이러한 경험을 통해 [공허한 마무리]" | 반드시 구체적 수치/학습 내용 결합 |
| "열정을 가지고" | 구체적 행동 ("새벽 2시까지 ~했습니다") |
| "성장할 수 있었습니다" | 무엇이 달라졌는지 구체 서술 |
| "귀사의 발전에 기여하고 싶습니다" | 직무와 연결된 구체적 기여 방식 |
| "어려움을 극복하고" | 장벽→선택→결과 순 서술 |
| "팀워크를 발휘하여" | 본인 역할 동사로 명시 |
| "주도적으로" | 실제 주도한 행동 기재 |
| "끊임없이 노력하며" | 삭제 후 행동 동사 대체 |
| "시너지" / "레버리지" | 한국어 동사로 풀어쓰기 |
| "~함으로써" 남발 | 2문장으로 분리 |
