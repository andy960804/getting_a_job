## [GATE 3] Anti-AI 리라이팅 체크 — v2 완료 후, PASS 후 v3 생성

### 문체
- [ ] **습니다체 전수 확인**: ~했다/~이다/~봤다 종결어미가 단 1개도 없는가?
- [ ] 첫 문장이 클리셰("저는" "귀사에")로 시작하지 않는가?
- [ ] 문장 길이가 섞여 있는가? (균일하면 짧은 문장 삽입)
- [ ] 동일 어미가 3회 연속 반복되지 않는가?
- [ ] 수동태("~이 됐습니다")가 3회 이상인가? → 능동태 전환
- [ ] 3C 마지막 문장이 "상황/문제"로 끝나고 4P 첫 문장이 행동 동사로 시작하는가?

### AI 상투어
- [ ] 블랙리스트 9개 표현이 없는가?
- [ ] "이러한 경험을 통해" 뒤에 구체적 수치/내용이 결합됐는가? (공허한 마무리 금지)
- [ ] "다양한"/"여러" → 구체적 열거로 대체했는가?
- [ ] "열정"/"노력" → 구체적 행동으로 대체했는가?
- [ ] "~함으로써" 2회 이상 → 문장 분리했는가?

### 내용
- [ ] 접속사가 문단당 1회 이하인가?
- [ ] "매우"/"정말"/"굉장히"가 전체 3회 이하인가?
- [ ] Hook과 Result에 수치·장면이 있는가?
- [ ] analyst 컬처핏 키워드가 자연스럽게 포함됐는가?

### 진실성
- [ ] 모든 사실이 경험 카드 기반인가? (없으면 `[미확인]` 태그)
- [ ] 수치·역할이 실제보다 부풀려지지 않았는가?
- [ ] 글자수가 요구 범위 ±10% 이내인가?
