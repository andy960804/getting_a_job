# Skill: 3단계 체크리스트

## [GATE 2] 비즈니스 레터 체크 — v1 완료 후, PASS 후 v2 진입
| # | 항목 | 기준 | FAIL 조치 |
|---|------|------|----------|
| 1 | 질문 일치 | 문항 요구에 정확히 답하는가? | 무관 문장 삭제 |
| 2 | 근거 객관성 | 결론이 수치·사실 기반인가? | 주관 → 수치/사실 교체 |
| 3 | 소제목 압축 | How+Result 요약인가? | "~~을 통해 ~~ 달성"으로 재작성 |
| 4 | 두괄식 배치 | 핵심이 첫 문장에 있는가? | 결론을 첫 문장으로 이동 |
| 5 | 직무 연결 | 직무→산업→직장 순 연결됐는가? | 직무 연결 최우선 |
| 6 | 단일 메시지 | 핵심 키워드가 하나인가? | 메시지 하나로 통일 |
| 7 | 문장 길이 | 쉼표 남발·2줄 이상 문장 없는가? | 긴 문장 2개로 분리 |

흔한 실패 패턴: 근거 없는 결론 / 배경(3C)만 있고 실행(4P) 없음 / 숫자 없음 / 직무 미연결

## [GATE 3] Anti-AI 리라이팅 체크 — v2 완료 후, PASS 후 v3 생성
### 문체
- [ ] 첫 문장이 클리셰("저는" "귀사에")로 시작하지 않는가?
- [ ] 문장 길이가 섞여 있는가? (균일하면 짧은 문장 삽입)
- [ ] 동일 어미가 3회 연속 반복되지 않는가?
- [ ] 수동태("~이 됐습니다")가 3회 이상인가? → 능동태 전환
### AI 상투어
- [ ] 블랙리스트 10개 표현이 없는가?
- [ ] "다양한"/"여러" → 구체적 열거로 대체했는가?
- [ ] "열정"/"노력" → 구체적 행동으로 대체했는가?
- [ ] "~함으로써" 2회 이상 → 문장 분리했는가?
### 내용
- [ ] 접속사가 문단당 1회 이하인가?
- [ ] "매우"/"정말"/"굉장히"가 전체 3회 이하인가?
- [ ] Hook과 Result에 수치·장면이 있는가?
- [ ] analyst 컬처핏 키워드가 자연스럽게 포함됐는가?
### 진실성
- [ ] 모든 사실이 경험 카드 기반인가? (없으면 `[미확인]` 태그)
- [ ] 수치·역할이 실제보다 부풀려지지 않았는가?
- [ ] 글자수가 요구 범위 ±10% 이내인가?

## [GATE 4] 최종 제출 전 점검 — v3 완료 후, PASS 후 제출
| # | 항목 | 기준 | FAIL 조치 |
|---|------|------|----------|
| 1 | 두괄식 | 첫 문장이 결론·핵심인가? | 결론 첫 문장으로 이동 |
| 2 | 구체화 | 추상 표현 없이 의미 전달되는가? | 수치·행동 동사로 교체 |
| 3 | 직무-산업-직장 연결 | 직무 연결이 최우선인가? | 직무 연결 추가 |
| 4 | 고객 요소 | C1 Customer가 포함됐는가? | "누구를 위한" 1문장 추가 |
| 5 | 액션 중심 | 배경보다 행동이 더 많은가? | 배경 3~4줄로 압축 |
| 6 | 핵심 액션 집중 | 가장 큰 영향 준 행동 하나가 명확한가? | 핵심 1개 선택 후 집중 |
| 7 | 진정성 | 회사 이름만 바꿔도 되는가? → NO여야 함 | 기업 특정 내용 추가 |
