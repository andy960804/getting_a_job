# Skill: 필살기 문항 작성 가이드

문항의 61%가 필살기형. 아래 3요소가 모두 드러나야 한다.

## ⚠️ 필수 원칙
- 모든 문장: **~습니다/~했습니다** 체 (비격식 어미 ~했다/~이다 전면 금지)
- 소제목: **[대괄호]** 형식 필수. 반드시 **[HOW + RESULT]** 형식으로 작성
- 단락 연결: 배경(1~2줄) → "이에/우선" + 행동 동사 → "그 결과" + 수치

---

## 필살기 3요소 × 문항 위치

| 요소 | 역할 | 위치 |
|------|------|------|
| 유사경험 | "나는 이 직무와 접점이 있다" 신호 | WHY 또는 Hook |
| 성공경험 | 수치·비교우위로 재현 가능성 증명 | WHAT + HOW |
| 인사이트 | 나만의 사고방식 — 학습능력·철학 | Insight |

---

## 실제 합격 자소서 구조 패턴

```
[소제목: 결과 또는 역량 — 수치 포함 권장]

[3C 배경 — 1~2줄]
"~한 상황이었습니다. ~라는 문제가 있었습니다."

[4P 실행 — 3~5줄, 행동 동사 중심]
"이에 [행동1]했습니다. 우선 [분석/방법]을 진행했습니다.
[행동2]한 결과, [중간 발견]임을 확인했습니다.
이를 바탕으로 [행동3]했습니다."

[결과 — 수치 필수]
"그 결과, [수치A]로 이어졌습니다. [수치B]를 달성했습니다."

[P4 외부 인정 — 선택]
"[발표/수상/공유] 등에서 인정받았습니다."

[인사이트 — 선택]
"이러한 경험을 통해 ~라는 것을 확인했습니다."
```

---

## 단락 연결 전환 예시

```
❌ 잘못된 전환
"이에 저는 5년치 데이터를 분석했습니다."   → "저는" 삭제

✅ 올바른 전환
"이에 5년치 불량 이력을 전수 분석했습니다."
"우선 공정별 심각 불량 빈도를 분류했습니다."
"그 결과 2개 공정에 불량이 집중됨을 확인했습니다."
```

## 마무리 포부 문장 패턴

```

"입사 후에도 ~을 통해 ~에 기여하겠습니다."
```

| 문항 타입 | 핵심 질문 | 비율 | 소제목 유형 | 참조 파일 |
|-----------|-----------|------|------------|-----------|
| 지원동기 | "왜 이 회사인가" — 로열티 검증 | 3C 60-70% / 4P 30% | `"역량명"` 또는 결론 선제시 | `db/references/example_지원동기.md` |
| 직무 관련 | "재현 가능성 증명" — 수치로 | 3C 20% / 4P 70% | `[HOW+RESULT]` 필수 | `db/references/example_직무관련.md` |
| 성장배경 | "어떻게 성장했는가" — 태도 증명 | 3C 배경 30% / 4P 행동 60% | 가치관 문장 허용 | `db/references/example_성장배경.md` |
| 성격 장단점 | "성격을 행동으로 증명하라" | 장벽 20% / 행동 60% / 결과 20% | `"성격 키워드"` 명사형 | `db/references/example_장단점.md` |

### 문항 타입별 첫 문장 패턴

```
지원동기:
"[직무명]은 [회사명]의 [핵심 가치] 생산에 기여하는 직무입니다."
"최근 [업계 이슈 수치]로 [직무 중요성]이 강조되고 있습니다."

직무 관련:
"[경험 요약 1줄]을 통해 [핵심 역량]을 체득했습니다."

성장배경:
"[시대/산업 배경] 속에서 [기존 한계]가 있었습니다."
인사이트형 소제목으로 시작 가능: "[가치관 한 문장]"

성격 장단점:
"[어려운 조건]에서 [성격 키워드]를 통해 극복한 경험이 있습니다."
```

### 문항 타입별 마무리 패턴

```
지원동기:   "~에 기여하겠습니다." (기업 특정 역할 명시)
직무 관련:  "이러한 경험을 바탕으로 ~에 기여하겠습니다." + 수치/경험 결합
성장배경:   "[태도]로 기아에서/○○에서 ~하는 엔지니어가 되겠습니다."
장단점:     "입사 후에도 ~을 통해 ~에 기여하고자 합니다."
```

## 수치화 우선순위 (모든 경험은 KPI로 설명 가능)

1. 비포-애프터: "기존 78분 → 48분으로 단축했습니다"
2. 무에서 유: "기존에 없던 X를 최초로 개발했습니다"
3. 비율·건수·기간·인원: "30% 절감", "50여 차례 실험", "16주간"
4. 외부 검증: "우수 과제 수상", "학술지 게재", "고객사 승인"

> 수치가 없으면 archivist의 KPI 전환 질문 7개 사용 (skills/archivist/3c4p_linter.md 참조)
