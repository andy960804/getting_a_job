# Skill: 성장과정·성격·장단점 작성 가이드

## 성장과정

### 기업이 보는 3가지
| 항목 | 포인트 |
|------|--------|
| 관계 | 윗사람·동료와의 관계 방식 |
| 세계관 | 친기업 정서인가 (반기업·남 탓 → 즉탈) |
| 성격 | 도전정신, 적응력, 끈기 |

### 3가지 전략 (상황에 맞게 선택)
- **직무 일관성형**: 관심 계기 → 직무 관련 경험 다발 → 필살기 연결
- **인생 전환점형**: 변화 계기 → 학습·에피소드 → 가치관 마무리
- **가치관 중심형**: 가치관 형성 계기 → 1~2 에피소드 → 회사 기여로 마무리

권장 가치관: `주도적` `성장형` `정직함` `적응력` `끈기` `배려`

### 절대 금지
- 남 탓, 권위자 갈등, 반기업 정서
- "힘들었지만 버텼습니다" 식 성장 없는 고생담

## 성격·장단점

### 면접관이 구분하는 3개념
| 개념 | 면접관 관점 | 포인트 |
|------|------------|--------|
| 강점 | 뽑아야 할 이유 | 직무 역량 직결 |
| 성격 | 함께 일하고 싶은지 | 타고난 기질·협업 |
| 내공 | 성숙도·멘탈 | "약점을 알고 보완 중" 어필 |

### 장점 구조
```
1개 핵심 특성 + 2개 이상 일관된 사례 (사례마다 KPI 수치 포함)
```

### 단점 구조 (반드시 이 순서)
```
1개 단점 특성 → 실제 사례 1개 → 극복 방안 → 극복 사례 1개
```
핵심: "나는 내 약점을 인지하고 있고, 보완하는 중입니다"

### 단점 금지 & 대체
| 금지 | 대체 |
|------|------|
| "고집스럽습니다" | "원칙을 중시합니다" (품질·윤리에 타협 없는 자세) |
| "유리 멘탈입니다" | 회복 탄력성 사례로 대체 |
| "완벽주의입니다" | 구체적 행동 패턴으로 대체 |
| 꾸며낸 단점 | 실제 에피소드 사용 |
