# Skill: 지원동기 작성 가이드

> 일반 필살기 문항과 **비율이 반대**. 반드시 별도 전략으로 접근.

## ⚠️ 필수 원칙
- 모든 문장: **~습니다/~했습니다/~겠습니다** 체 (비격식 어미 전면 금지)
- 단락 연결: 3C 기업 분석 → 4P 내 기여 전환 시 "그 이유는 명확합니다" / "지원 이유는 단순합니다" 등 브리지 문장 1개 삽입

## 본질
"왜 이 직무인가"가 아닌 **"왜 이 회사인가"** — 로열티 검증.
경쟁사 이름만 바꿔도 되는 자소서 = 즉시 탈락.

## 구조 및 비율
```
[소제목]        필살기(직무 강점) + 입사 후 포부
                예: "○○ 역량으로 [기업명] ○○ 향상에 기여"

[3C 기업분석]   60~70% ← 일반 문항보다 훨씬 높음
  C1: 차별화된 기술력·상품 (상품·서비스명 직접 명시)
  C2: 사업 특징 (지역성·독점구조·미래 투자 방향)
  C3: 수치화된 성장률·실적 (경제신문 스크랩 기반)

[4P 내 기여]    20~30%
  기업 경쟁력 → 내 필살기 강점 연결
  여러 필살기 나열 가능

[인사이트]      선택 (글자수 여유 있을 때만)
```

## 단락 연결 예시 (3C → 4P)

```
[3C 기업 분석 마지막 — 선택 근거로 마감]
"기술과 제조 양쪽을 동시에 혁신하는 회사는 많지 않습니다."

[브리지 문장 — 1줄로 전환]
"지원 이유는 명확합니다."  ← 짧게, 단호하게

[4P 내 기여 첫 문장 — 내 자산 수치로 시작]
"약 2년간 자동차 Tier1에서 공정개발·4M변경·외주 관리를 수행했습니다."
```

## 첫 문장 권장 패턴 (실제 합격 사례)

| 유형 | 예시 |
|------|------|
| 업계 이슈 | "최근 1년 사이 하이브리드 차량 생산량은 전년 대비 46% 이상 증가했습니다." |
| 기업 차별화 | "기술과 제조 양쪽을 동시에 혁신하는 회사는 많지 않습니다." |
| 결론 선제시 | "○○에 지원한 이유는 단 하나입니다 — [기업 핵심 경쟁력]입니다." |

금지 오프닝: "저는", "귀사에 지원하게 된", "항상 ~을 꿈꿔온"

---

## 준비 방법
- 매일경제·한국경제 스크랩 → 기술력·성장률·사업 특징 수집
- 현직자 인터뷰 → 사업 경쟁력·문화·정량 실적

## 특수 케이스 & 금지
- 필살기 문항 없는 기업(삼성·LG 등): 지원동기에 필살기 통합
- 사회공헌·비전만 언급 → 경쟁력 분석 없음 → 삭제
