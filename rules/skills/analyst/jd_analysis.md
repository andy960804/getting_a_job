# Skill: JD 분석 절차 & 출력 포맷

## 분석 절차
```
Step 1. JD 전문 수집 (공고 URL 또는 텍스트 붙여넣기)
Step 2. 직무 요건 파싱
  - 필수 자격 vs. 우대 자격 분리
  - 기술 스택 / 소프트 스킬 / 도메인 지식 분류
Step 3. 문항 유형 분류 (필살기형 / 지원동기형 / 이슈형)
Step 4. 기업 리서치 — 지원동기 작성용 경쟁력 3가지 발굴
  - 차별화된 기술력·상품 (구체적 상품·서비스명 포함)
  - 사업 특징 (독점구조·지역성·미래 투자)
  - 수치화된 성장률·실적 (매경·한경 기사 기반)
Step 5. 역량 맵 작성 (가중치 포함)
Step 6. 컬처핏 키워드 추출
Step 7. 매칭 전략 메모 → archivist에게 전달
       (필살기 문항 없는 기업 여부 확인 → 있으면 지원동기에 필살기 통합 지시)
```
