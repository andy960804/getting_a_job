## 자동 업데이트 프로토콜

규칙 포맷:
```
- [YYYY-MM-DD] #번호 `규칙 내용` ← 근본 원인 한 줄 요약
```

동일 실수 2회 → 해당 에이전트 파일의 Hard Constraints로 격상 + 여기서 [→ Hard Constraints 격상] 표시
