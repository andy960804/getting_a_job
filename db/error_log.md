# Error Log — 실수·오류 누적 기록

> 이 파일은 프로젝트 진행 중 발생한 모든 실수를 구조화해서 기록한다.
> 실수가 발생하면 Claude가 **즉시** 이 파일에 로그를 추가하고,
> 해당 에이전트의 `Learned Constraints` 섹션을 동시에 업데이트한다.

---

## 로그 작성 프로토콜

실수 감지 트리거:
- 사용자가 Claude의 출력을 수정하거나 "틀렸다", "다시 해줘"로 정정할 때
- Linter / Hard Constraints 게이트가 동일한 이유로 반복 실패할 때
- 저장된 파일이 규칙과 불일치할 때 (파일명, 포맷, 구조)
- 사용자가 명시적으로 실수를 지적할 때

로그 추가 즉시 수행 사항:
1. 아래 템플릿으로 이 파일에 기록
2. 담당 에이전트의 `Learned Constraints` 섹션에 규칙 추가
3. 동일 실수가 2회 이상이면 Hard Constraints로 격상

---

## 로그 템플릿

```markdown
### [YYYY-MM-DD] #번호 — [실수 제목]

- **발생 에이전트**: analyst / archivist / ghostwriter / system
- **트리거**: 사용자 정정 / 게이트 반복 실패 / 파일 불일치 / 명시적 지적
- **무엇이 잘못됐는가**: (구체적 상황)
- **왜 발생했는가**: (근본 원인)
- **어떻게 수정했는가**: (즉시 조치)
- **재발 방지 규칙**: (Learned Constraints에 추가할 문장)
- **격상 여부**: Hard Constraints 격상 / 유지
```
