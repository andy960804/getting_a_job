# AI 기반 PCP Audit 자동화 프로그램 개발

## 메타
- 기간: 2026.01 ~ 2026.03 | 역할: 공정개발 담당 (기획·개발·보고 전 과정 단독 주도) | 태그: `문제해결능력` `실행력·추진력` [필살기 A급]

## 원문 요약 (사용자 덤핑 핵심 그대로 — 압축 금지)
> Process Control Plan 정기 감사(PCP Audit)는 관리계획서를 기준으로 작업표준서·공정흐름도·일상점검표를 비교해 불일치·누락을 찾는 작업이다. 사람이 직접 하면 "눈이 빠지도록 문서를 뒤져가며 찾아야" 하는 구조였다. AI 자동화에 개인적으로 관심이 많았고, 이 작업이 너무 비효율적이라는 생각이 들어 자발적으로 프로그램 개발을 시작했다. 처음에는 Qwen3 0.6B로 유사도를 계산했으나 모델 성능 한계로 개선이 필요했고, 최종적으로 Claude API를 연결해 문제를 해결했다.

## 3C — Why

### C1 Customer
생산기술팀 공정개발 담당자 7명. 각자 담당 아이템의 라인 PCP Audit를 직접 수행하며, 13개 라인 × 연 2회 = **연 26회 감사**가 발생한다. 감사 1회당 4시간 소요로 연간 총 104시간을 문서 비교 작업에 투입해야 했다. 자동화 전에는 문서를 눈으로 일일이 대조해야 해서 **오탐·누락 위험과 높은 시간 비용**이 동시에 존재했다.

### C2 Company
생산기술팀 차원에서 PCP Audit 효율화를 공식 추진한 것이 아니라, **담당자 본인이 문제를 직접 발견하고 자발적으로 개발을 시작**했다. 도전과제는 명확했다: 관리계획서-표준류 문서 간 비교는 텍스트의 의미적 유사도를 판단해야 하는 작업인데, 기존에는 이를 판단할 도구가 전혀 없었다. 개발 과정에서 코딩은 AI(Claude Code 등)를 활용했으며, 기획·모델 선택·테스트·보고까지 **전 과정을 혼자 주도**했다.

### C3 Competitor
엑셀 매크로를 대안으로 검토했으나, **텍스트 의미 유사도를 판별하는 데에는 엑셀 매크로가 구조적으로 부적합**하다고 판단해 기각했다. 외부 상용 솔루션은 별도 조사 없이 자체 개발 경로를 선택했다.

## 4P — What & How

### P1 Product
Python 기반 GUI 애플리케이션으로, 관리계획서와 비교 대상 문서(작업표준서·공정흐름도·일상점검표)를 공정 단위로 파싱한 뒤 Claude API를 통해 유사도를 계산하고 결과를 Excel 감사 보고서로 자동 생성하는 프로그램. **MATCH/PARTIAL/MISMATCH/MISSING/EXTRA 5단계 판정 + 색상 코딩**으로 불일치 항목을 즉시 식별 가능하다. 개발 경로: Qwen3 0.6B(생성형, 성능 한계) → Claude API(최종) 로 개선.

### P2 Place
회사 지급 노트북에서 실행 가능한 독립 실행형 앱으로 개발했다. Qwen3 0.6B를 처음 선택한 이유는 **"회사 노트북으로 돌아갈 수 있는 최선의 사양을 가진 모델"**이었고, 한국어·영어·숫자가 혼용된 제조업 문서 맥락 이해에도 유리했기 때문이다. 이후 Claude API를 연결해 유사도 판정 정확도를 높이는 방향으로 발전시켰다. 생산기술팀 내부 배포.

### P3 Price
- **감사 1회 소요시간: 4시간 → 5분 (98.6% 단축)**
- 연간 절감 시간: 104시간 → 약 2.2시간 (연 101시간 절감)
- 7명 기준 팀 전체로 확장 시 연 700시간 이상의 잠재 절감 효과
- 수치가 의미 있는 이유: 단순 시간 단축이 아니라 **사람이 하면 오탐·누락이 발생할 수 있는 작업을 AI가 일관된 기준으로 처리**한다는 정확도 측면의 가치도 동반

### P4 Promotion
PPT 자료 + 실제 시연으로 팀 내 정식 보고를 진행했다. 발표 내용: 개발 동기 → 자동화 원리(AI 유사도 판정 방식) 설명 → 라이브 시연. 결과: **생산기술팀(공정개발 담당 7명) 공식 채택, 현재 실사용 중**.

## 핵심 인사이트
"문서 비교라는 반복적·수동적 작업을 AI 유사도 판정으로 자동화함으로써, 사람의 시간을 98% 이상 줄이면서 동시에 판정 일관성도 확보할 수 있다는 것을 실증했다."
