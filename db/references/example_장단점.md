# [성격의 장단점] 최우수 참조 예시
출처: 한국화낙 기술지원 2026 상반기 합격 자소서 — 4번 문항

## 원문

"긍정적인 말의 힘"

처음 다루는 프로그래밍 언어와 제품, 촉박한 개발 일정으로 인해 정신적으로 힘들었던 경험을 긍정적인 단어를 통해 끈기 있는 자세로 극복한 경험이 있습니다. STM32 프로젝트에서 타 지역 학교 학생들과 팀을 이루어 리더 역할을 맡았습니다. 시스템 개발을 하기 전, 단계별 Quest를 진행하며 온통 영어로 된 ST의 공식 기술 문서와 동영상 가이드를 참조하는 것은 여간 쉬운 일이 아니었습니다. TouchGFX의 GUI 개발을 위해 필요한 WildCard 기능을 사용하기 위해서 다뤄본 적 없는 C++의 모듈과 클래스 개념에 대한 기초적인 지식이 있어야 헤더 파일을 이해할 수 있었습니다. 그럼에도 불구하고, 난제의 해결의 실마리가 보이면 긍정적인 단어를 외치며 끈기 있는 태도를 유지하는 것에 노력했습니다. 될 때까지 하겠다는 꾸준함으로 버텼고, 주최 측에서 요구하는 약 40개의 기능 구현을 원하는 기한 내에 달성했습니다. 그 결과, 3등을 수상할 수 있었습니다. 한국화낙에 입사해서 문제 상황에서 원인을 분석하고 해결책을 찾는 과정에서 긍정적인 단어를 사용하며 회사와 팀에 더 좋은 분위기를 만들어가며 업무에 임하고자 합니다.

"아이들이 학업적으로 발전하고 정서적으로 성숙해지는 모습을 보면서 '멘토링을 통한 배움의 선순환 고리'에 기여했다는 자부심을 느꼈습니다."

"아이들이 학업적으로 발전하고 정서적으로 성숙해지는 모습을 보면서..." — 타인의 변화를 끌어낸 경험으로 성격(리더십·공감 능력)을 증명

---

## 잘된 이유 분석

1. **소제목이 성격을 직접 명시**: "긍정적인 말의 힘" — 면접관이 소제목만 봐도 이 사람의 강점이 무엇인지 바로 파악
2. **장벽 → 행동 → 결과 구조**: 어려운 상황(처음 다루는 언어, 촉박한 일정) → 구체적 대응 방식(긍정적 단어, 꾸준함) → 수치 결과(40개 기능 구현, 3등 수상)
3. **성격을 "행동"으로 증명**: "긍정적이다"는 주장이 아닌 "긍정적인 단어를 외쳤습니다"라는 행동 서술
4. **입사 후 연결**: 단순한 과거 서술로 끝나지 않고 "입사 후에도 이렇게 하겠습니다"로 연결 — 재현 가능성 증명
5. **겸손도 조절**: "~노력했습니다" 사용 — 자화자찬 없이 과정과 결과로만 증명

---

## 이 예시에서 추출한 스타일 패턴

- **장단점 소제목**: 성격 키워드를 명사형 또는 짧은 문장으로 — `"긍정적인 말의 힘"`, `"아이들의 목표 설정과 실천을 주도하다"`
- **장점 서술 구조**: `상황(어려운 조건 명시) → 나의 대응 방식(행동 동사) → 결과 수치 → 입사 후 적용`
- **단점 서술 구조**: `단점 인정(1줄, 직접적으로) → 극복 행동(2~3줄) → 현재 상태(개선됨)`
- **겸손 표현 패턴**:
  - "~에 노력했습니다" — 과정 겸손
  - "~할 수 있었습니다" — 결과 겸손
  - "~자신이 있습니다" — 자신감 표현 (결론부에서만)
- **금지 표현**: "저는 긍정적인 사람입니다" — 주장형. 행동으로 보여주고 클레임은 결론에서만
- **수치 필수**: 기능 수(40개), 수상 순위(3등), 기간(~주간) 중 최소 1개
